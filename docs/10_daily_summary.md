# Daily summary

The phone app now includes a Daily summary screen from the signed-in home page. It reads only the current worker's active local records for today's visit date.

The screen shows:

- Hotspots visited today, counted by distinct hotspot ID.
- Total client records today.
- Unique people today, counted by distinct client code across today's hotspots.
- DIC referrals.
- New, Old and Not specified client type totals.
- Tested and Reactive counts for HIV, HCV, HBV and Syphilis. A result of No means not tested.
- Distribution totals for 3cc, 1cc, LDS, alcohol swab, sterile water and condom.
- Recollection totals for 3cc, 1cc and LDS.

Deleted records are excluded. Repeated visits by the same client code at different hotspots count as multiple records but one unique person for the day.
